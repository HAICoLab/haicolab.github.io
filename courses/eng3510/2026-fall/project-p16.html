PROJECT 16   /   교육 · 학습 계획

SmartStudy AI: 맞춤형 학습 전략 설계

회독 일정의 자동 재조정과 PDF 기반 예상문제 생성을 결합한 학습 도우미를 구현했습니다.

프로젝트 살펴보기

01 문제 상황02 모델·데이터03 구현 과정04 핵심 결과05 한계·발전 방향

01 문제 상황

시험 준비에서는 무엇을 공부할지뿐 아니라 회독 간 시간을 나누고 밀린 계획을 다시 짜는 데도 에너지가 듭니다. 시험 일정과 학습 자료를 입력하면 계획·실행·연습문제가 이어지는 서비스를 목표로 했습니다.

02 사용 모델과 데이터

모델·기술

  • Python 규칙 기반 일정 알고리즘: 회독 구간과 공부 불가일을 반영하고 미수행 학습량을 재배분합니다.
  • OpenRouter를 통한 LLM API: PDF의 핵심 개념과 예상문제·정답·해설을 생성합니다. 사용한 기반 모델 버전은 자료에 명확히 제시되지 않았습니다.

데이터·입력

  • 시험 날짜, 과목, 학습 범위, 공부할 수 없는 날과 과제 수행 기록.
  • 사용자가 올린 PDF의 지정 페이지, 키워드 주변 문맥 및 내용을 보완하는 공개 자료.

03 구현 과정

  1. 시험일까지의 가용 날짜를 회독·기출 연습·최종 정리 구간으로 배분하고 수행 상태에 따라 재조정합니다.
  2. PDF를 범위별로 추출·분할하고 핵심 키워드를 뽑아 중복을 합치고 중요도를 정렬합니다.
  3. 키워드의 문맥으로 문제를 만들고 정답·해설은 분리 생성한 뒤, 형식 오류와 낮은 신뢰도 출력을 걸러 제공합니다.

04 핵심 결과

  • 회독 계획, 캘린더, 미수행 일정 재조정, PDF 예상문제 생성의 주요 흐름을 구현했습니다.
  • 자료 추출부터 문제 출력까지 세분화한 파이프라인에 JSON 응답 복구, 재시도, 병렬 처리와 수식 렌더링을 적용했습니다.

05 한계와 발전 방향

  • 자료의 기술 스택·일부 기능 상태에 서로 다른 설명이 있어, 전체 기능의 상용 운영 완료로 해석하지 않았습니다.
  • 생성 문제의 정답률이나 학습 성적 개선을 검증한 수치가 없습니다. 모델이 부여한 신뢰도 역시 실제 정답 보증은 아닙니다.

자료: 최종보고서 및 발표자료. 제출 자료를 바탕으로 정리했으며, 결과는 해당 프로젝트의 구현·실험 범위에 해당합니다.
