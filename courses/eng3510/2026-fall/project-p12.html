PROJECT 12   /   컴퓨터 비전 · 물리 모델링

이미지 기반 투사체 측정 및 미래 궤적 예측

연속된 세 장의 이미지에서 공의 위치를 찾고, 거리 추정과 운동 방정식으로 미래 프레임을 생성합니다.

프로젝트 살펴보기

01 문제 상황02 모델·데이터03 구현 과정04 핵심 결과05 한계·발전 방향

01 문제 상황

공의 속도와 궤적 분석에 쓰이는 특수 장비 대신, 일반 이미지로 투사체의 움직임을 추정할 수 있는지 탐구했습니다. 화면의 픽셀 위치·크기를 물리 좌표로 바꾸고 미래 위치까지 연결하는 경량 엔진이 목표입니다.

02 사용 모델과 데이터

모델·기술

  • OpenCV와 KMeans: 이진화한 이미지에서 잡음과 공을 구분하고 중심 좌표를 추정합니다.
  • scikit-learn 선형 회귀: 공의 반지름 역수와 거리의 관계를 보정합니다. 이후 계산에는 NumPy와 고전역학의 운동 방정식을 사용합니다.

데이터·입력

  • 지름 7.3cm의 공과 중력 조건을 설정한 시뮬레이션에서 생성한 연속 3프레임.
  • 카메라 거리별 공의 픽셀 크기와 좌표에 백색 잡음을 추가한 가상 데이터 및 별도로 입력한 테스트 프레임.

03 구현 과정

  1. 가상 이미지로 거리 추정 가중치를 학습하고 저장합니다.
  2. 세 프레임에서 공의 중심과 반지름을 추출해 실제 좌표로 환산한 뒤 속도와 가속도를 역산합니다.
  3. 마지막 프레임에서 0.1·0.2·0.3초 뒤의 위치와 크기를 계산해 새로운 이미지로 출력합니다.

04 핵심 결과

  • 데이터 생성, 객체 위치 추출, 거리 보정, 물리 계산, 미래 프레임 출력을 하나의 파이프라인으로 구현했습니다.
  • 초기 가중치를 의도적으로 낮춘 후 시뮬레이션의 기준값에 가까워지는지 확인하고, 출력 프레임의 연속성을 시각적으로 검토했습니다.

05 한계와 발전 방향

  • 검증은 주로 가상 데이터에 기반하며 실제 스포츠 촬영에서의 위치 오차·속도 오차는 보고되지 않았습니다.
  • 회전, 공기 저항, 렌즈 왜곡 등 다양한 현실 조건은 충분히 다루지 못했습니다. 발표자료의 그래프는 구현 설명용 예시로 구분합니다.

자료: 최종보고서 및 발표자료. 제출 자료를 바탕으로 정리했으며, 결과는 해당 프로젝트의 구현·실험 범위에 해당합니다.
